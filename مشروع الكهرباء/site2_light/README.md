# موقع المؤسسة العامة للكهرباء والطاقة

 مشروع مقرر تصميم الويب، وتحتوي على الصفحات الأساسية المطلوبة .

## الصفحات

```text
html/
├── index.html       الصفحة الرئيسية والسلايدر
├── services.html    الخدمات
├── contact.html     التواصل مع Font Awesome ونموذج التواصل
├── login.html       تسجيل الدخول مع Validation
├── register.html    إنشاء الحساب مع Validation وModal Ajax
└── bills.html       الفواتير وModal Ajax والفيديو المحلي
```

## المجلدات والملفات

```text
css/style.css
js/script.js
js/bill.json
js/terms.html
images/slide1.svg
images/slide2.svg
images/slide3.svg
videos/payment-tutorial.mp4
```

## المتطلبات المطبقة

- HTML5 Layout باستخدام header وnav وsection وaside وfooter.
- العناوين والفقرات والقوائم والجداول والنماذج.
- ست صفحات، منها صفحة تواصل.
- Font Awesome في صفحة التواصل.
- تسجيل الدخول وإنشاء الحساب مع Validation.
- شريط صور متحرك مع أزرار ونقاط وانتقال تلقائي.
- Grid وFlexbox.
- Responsive Design باستخدام Media Queries.
- Toast Notification بواسطة Toastr.
- نافذتا Modal يتم تحميل محتواهما بواسطة Ajax: الفاتورة والشروط.
- Bootstrap وjQuery.
- فيديو محلي داخل مجلد videos.

## التشغيل

شغّل `html/index.html` بواسطة Live Server في VS Code حتى تعمل طلبات Ajax. الشهادة ترفق بشكل منفصل من الطالب، ورابط GitHub يضاف بعد رفع المشروع.
